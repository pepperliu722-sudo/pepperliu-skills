# pepperliu-skills

Reusable Codex skills for product demos, growth, and Humanizer.help workflows.

## Skills

### [Create Quiet Humanist Designs](https://github.com/pepperliu722-sudo/create-quiet-humanist-designs)

Turn a feature, service, event, argument or story into a finished artistic editorial design with content-specific handmade imagery, non-template composition and exact typography. It works across posters, social graphics, email, presentations, covers, web heroes, invitations and small campaigns.

```bash
npx skills add pepperliu722-sudo/create-quiet-humanist-designs --skill create-quiet-humanist-designs
```

The skill now has its own repository so its examples, documentation, releases and stars can grow independently.

### Product Demo Video Storyteller

Create high-resolution product use-case videos that reproduce the real product UI one-to-one and demonstrate each feature's actual input, action, output, and evidence. It prevents generic UI, incorrect controls, unrelated result screens, unreadable output, and visual mismatch with the source website.

Download [product-demo-video-storyteller.zip](./product-demo-video-storyteller.zip) to install the first skill package.
