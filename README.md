# pepperliu-skills

Reusable Codex skills for product demos, growth, and Humanizer.help workflows.

## Quiet Humanist Design

Create a coherent visual language for posters, email campaigns and headers, PowerPoint or slide decks, social graphics, covers, web hero sections, invitations, infographics, and other image-led design. The skill combines cinematic negative space, one clear visual metaphor, handmade marks, paper texture, restrained color, editorial typography, and human-scale imperfections while adapting the system to each medium.

Use the skill from [`skills/create-quiet-humanist-designs`](./skills/create-quiet-humanist-designs).

## Product Demo Video Storyteller

Create high-resolution product use-case videos that reproduce the real product UI one-to-one and demonstrate each feature's actual input, action, output, and evidence. It prevents generic UI, incorrect controls, unrelated result screens, unreadable output, and visual mismatch with the source website.

Download [product-demo-video-storyteller.zip](./product-demo-video-storyteller.zip) to install the first skill package.
